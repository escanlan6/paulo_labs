# Week 1 laboratory — start here

This is a formative laboratory. Nothing is submitted for marks.

1. Extract the whole ZIP file to a normal folder. Do not work from inside the ZIP.
2. Open the extracted `week01_lab` folder in your coding environment.
3. Open `week01_lab.qmd` to write and run R code.
4. Keep the `data` folder beside `week01_lab.qmd`; the worksheet finds it automatically.
5. If R reports that a package is missing, run this once in the R console:

   ```r
   install.packages(c("tidyverse", "scales"))
   ```

6. Run the setup chunk, then work through the numbered tasks in order.
7. Render the QMD file when you want a clean HTML record of your work.

`week01_lab.html` is a read-only browser version of the blank worksheet. Use it if you want to read the instructions without opening Quarto.

The data are deliberately frozen. Do not replace them with live downloads: everyone should analyse the same observations.
